# 📘 Data Analytics – Exercises & Handwritten Learning

## 📌 Overview

This repository contains the exercises completed as part of my Data Analytics learning journey.

The exercises were initially completed by hand as part of the learning and assessment process. The purpose was to demonstrate my understanding of the concepts before progressing to practical implementation using coding platforms such as **Databricks** and other Data Analytics tools.

The handwritten exercises provided an opportunity to understand the **logic, concepts, calculations, and analytical processes** before applying them through code.
